# Concourse

Documentation for the Concourse pipelines and tasks in this repository.

[Concourse](https://concourse-ci.org/) is a CI/CD automation platform. Pipelines in this repository are organized by purpose under [`.concourse/`](../../../.concourse), with supporting tasks and shared templates grouped alongside them.

Each pipeline or task should have its own documentation page explaining what it does, what inputs it expects, and how it is meant to be used.
